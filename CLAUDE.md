# narrate — Homalabs screen studio
Load the `homalabs-studio` skill (`.claude/skills/homalabs-studio/SKILL.md`) before doing anything here; it holds the owner's rules and current state. The product spec is `docs/SPEC.md` plus the add-on `docs/SPEC-ADDON.md` (Smart Director, derivative assets, Asset Studio); both govern all work.

Work happens on two machines (Windows laptop and Mac) and two Claude accounts, synced only through GitHub `Tassyomah/homalabs-studio`. Start every session with `git pull`; after a finished, tested task, commit and push so the other machine can pick it up. On a Mac with no build yet, follow `docs/DEVELOPMENT.md` → macOS and the "Continuing on her Mac" section of the skill.
